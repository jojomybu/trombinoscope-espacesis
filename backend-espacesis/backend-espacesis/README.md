# Backend API - Trombinoscope ESPACESIS

Ce dossier contient l'API REST développée avec **FastAPI**. Elle permet de gérer les membres du club et de rendre les données persistantes.

## 🚀 Installation

Avant de commencer, assurez-vous d'être bien positionné dans le dossier du backend :
`cd backend-espacesis`

### 1. Préparation de l'environnement
Créez et activez votre environnement virtuel pour isoler les dépendances du projet :

```bash
# Création de l'environnement virtuel
python3 -m venv venv

# Activation (Linux/macOS)
source venv/bin/activate

# Activation (Windows)
venv\Scripts\activate
